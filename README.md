# Barkoff 🐶

[![Barkoff demo video](https://img.youtube.com/vi/ZQb9UBLhy-g/maxresdefault.jpg)](https://www.youtube.com/watch?v=ZQb9UBLhy-g)

**Meet strangers online and battle it out with your best animal sounds.**

Built solo at DDoSki's Hack Night · [Devpost](https://devpost.com/software/barkoff)

## About

- Real-time platform that pairs strangers in live video matches
- Players go head to head with their best barks and roars
- Spectrogram analysis scores every sound live
- Built-in moderation keeps matches safe

## Tech Stack

- **Frontend:** Next.js and React in TypeScript
- **Backend:** Express.js with signaling and webhooks for live conferencing
- **Audio:** spectrogram analysis and sound embeddings for scoring
- **Hosting:** Cloudflare Tunnel demo deployment
